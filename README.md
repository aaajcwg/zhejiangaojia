# 浙江建材报价系统（手机版 / 实时价）

一个**纯前端单文件 HTML** 的建材报价工具，适配手机，打开即拉取最新价。无需安装、可离线兜底。

## 功能

- **报价单**：选材料 → 填数量/损耗 → 自动算小计、材料费合计、运费、税额、含税总价，并生成人民币大写金额；可保存历史单、导出 CSV、一键打印/导出 PDF。
- **材料库**：内置约 50 项浙江常见建材（水泥骨料、钢材、砖瓦石材、管材、电线电缆、涂料化工、防水保温、门窗、五金劳保等）及参考单价；支持搜索、分类筛选、新增/编辑/删除、导入/导出 CSV。
- **地区系数**：杭州/宁波/温州/嘉兴/湖州/绍兴/金华/衢州/舟山/台州/丽水 11 个地市各有系数，按所选城市自动换算单价（基准＝杭州）。
- **设置**：公司信息、默认税率/运费/损耗、各地市系数均可自定义；数据存浏览器 localStorage。

## 实时价格怎么更新

价格通过「设置 → 数据源地址」实时拉取，默认 `./prices.json`（格式 `{city,date,source,items:[{name,category,spec,unit,price}]}`），**打开页面自动 fetch**。

三种更新方式：

1. **托管后自动拉 `prices.json`**（最稳）：把本仓库部署到任意静态托管（GitHub Pages / NAS / k3s / 局域网 `node server.js`），手机同网络打开即取最新价。
2. **导入造价期刊 CSV → 导出 `prices.json`**：电脑端「数据源 → 导入 CSV」（列：`名称,分类,规格,单位,价格`），再「导出 prices.json」上传到托管目录，手机刷新即得。
3. **公共 CORS 代理直连造价站**（可选勾选）：尝试取浙江造价管理总站 `zjzjgl.zj.gov.cn` 最新期链接（仅提示，不能结构化解析价格，已如实标注）。

> ⚠️ 关于"实时"口径：浙江造价网发布的是**月刊/季刊"信息价"**，非秒级现货价；PDF 自动解析不稳定，故以"你维护的 prices.json 自动下发"为主，内置杭州参考价为**兜底样本**（已标注"需校对"）。如需 mysteel 等秒级现货价，需自备账号/token 另接数据源。

## 使用方法

### 方式 A：直接双击（离线）
双击 `zhejiang-building-material-quote.html` 用浏览器打开即可使用；数据存本地，离线兜底内置参考价。

### 方式 B：部署到 Web（手机可访问 + 实时价，推荐）
任选其一托管 `zhejiang-building-material-quote.html` + `prices.json` 两个文件：

- **GitHub Pages**：把本仓库开启 Pages（Settings → Pages → 选 main 分支根目录），手机开 `https://aaajcwg.github.io/zhejiangaojia/`。
- **本机/局域网**：`node server.js`，手机连同一 WiFi 开 `http://<本机IP>:3000`。
- **NAS / k3s**：把两个文件放到静态目录/Ingress 后，手机直接开网址。

## 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | 主程序（单文件，手机自适应）；仓库根路径 `https://aaajcwg.github.io/zhejiangaojia/` 直接打开 |
| `prices.json` | 示例价格数据（杭州基准，51 项），托管后默认数据源 |
| `server.js` | 可选纯静态托管脚本（零依赖，`node server.js` 起服务） |
